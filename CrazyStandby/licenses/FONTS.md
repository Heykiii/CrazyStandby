# Fonts used for the "number styles"

All four fonts are free under the SIL Open Font License 1.1 (texts in this folder) and come from Google Fonts.

| Number style in the app | File in res/font | Real font |
|---|---|---|
| Give You Glory | give_you_glory.ttf | Give You Glory |
| Calligraphy (Zapfino-style) | calligraphy.ttf | Great Vibes |
| Baseball | baseball.ttf | Lobster |
| Varsity | varsity.ttf | Graduate |

Zapfino is an Apple font and cannot be bundled in an Android app. Great Vibes is a free calligraphy look-alike.
To use your own licensed font instead, replace the .ttf file with the same name (all lowercase, no spaces).
